# Консольное приложение
## Автор
Пономарев А.С.
## Описание
 Консольное приложение на C#, демонстрирующее работу с обобщёнными типами.
### Классы:
- **PrivateClass<T>** – хранение значения с private полем.
- **Swapper** – обмен переменных (ref) и печать коллекций.
- **MinMax** – нахождение min/max (только для IComparable).
- **Container<T>** – контейнер результата операции.
- **Person** – пример пользовательского типа с ToString().
- **Factory** – фабричные методы успешного/неуспешного результата.
### Основные действия:
- Создание контейнеров для float и bool.
- Обмен значениями int и string.
- Поиск min/max для int, double, char.
- Создание Person с валидацией через ResultContainer.
